# person

The `person` family: `person_name` and `person_name_lite`.

- `person_name` is rule-based NER and replaces the TS `compromise` wrapper.
  Its metadata matches TS but its matches do not, so it is held to the eval
  corpus rather than to golden parity. See the module docs for the rules.
- `person_name_lite` ports `person-name-lite.ts`. The `regex` crate has no
  lookahead, so its pattern is matched by hand with the same leftmost-first
  result.
- `bloom.rs` reads the bloom filter in place from `bloom.bin` and `data.rs`.
  Both are generated by `packages/sensored/scripts/generate-bloom-filter.ts`;
  do not edit them. The hashing (FNV-1a and DJB2 over UTF-16 units) must
  match the script bit for bit.
- `lexicon.rs` holds the hand-written word lists. Each list is lowercase,
  sorted and deduplicated.
- `bloom.bin` is in the crate's `include` list, so the published crate
  carries it.
