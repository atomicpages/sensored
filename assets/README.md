# Sensored logo assets

Based on the selected “Balanced” visual proof. Colors: slate black `#0B0F14`, mint `#00E5A0`, white `#FFFFFF`.

- `horizontal-light.svg`, `horizontal-dark.svg`: icon and wordmark, transparent canvas; place on light or dark backgrounds respectively.
- `horizontal-mono.svg`: one-color foreground treatment.
- `wordmark-*.svg`: outlined `sen[so]red` typography on transparent canvas.
- `icon-*.svg`: terminal mark at the named intrinsic size, including tiny variants.
- `github-avatar.svg`, `favicon.svg`: icon presets.
- `social-preview.svg`: 1280 × 640 preview.

The lettering and icon use vector paths; the social preview caption uses a monospace font fallback. To use as a GitHub social preview, export that SVG to PNG because GitHub's preview uploader expects a raster image.

The original proof was a raster concept sheet, so this is a hand-built vector interpretation rather than an exact trace. The selected span remains readable as `sen[so]red`.
