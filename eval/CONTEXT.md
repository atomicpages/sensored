# Independent evaluation tooling

Bun-only development tooling, outside the published src/ boundary. evaluator.ts
validates versioned labeled corpora and scores exact original UTF-16
(ruleId, start, end) tuples before transformation. cli.ts adapts inspect groups
back into those tuples. evaluator.test.ts is synthetic evaluator verification;
it is NOT independent quality evidence.

## Independent corpus

The independent corpus is generated by `generate-corpus.ts` using
`@faker-js/faker` with a fixed seed (42) for reproducibility. The corpus is
synthetic — no real PII is included. Independence comes from the data being
separately owned, reviewed, and independent from detector development: the
expected spans are computed by construction (PII is inserted at a known
position), not by running the detector. Contributor fixtures in `test/` do
not count as independent evaluation evidence.

Corpus revision: `independent`.
Provenance: `independent`.

The corpus is committed to the repository as `eval/corpus.json` because it
contains only synthetic faker-generated data with no privacy concerns. The
baseline report is committed as `eval/baseline.json`.

## Release gate

The gate requires `provenance === "independent"` and `reviewed === true`,
at least 1000 negative documents, at least 200 positive occurrences per
detector (all 131 detectors), >= 99% precision and >= 95% recall per
detector, and a matching baseline report. Any new FP, FN, or lost TP tuple
against the baseline blocks release. A changed corpus fingerprint requires
re-baselining.

## False-positive review workflow

When the evaluator reports a false positive:
1. Identify the case by its opaque ID in the report.
2. Review the corpus case text and expected labels.
3. If the label is wrong, fix the corpus generator and regenerate.
4. If the detector is wrong, file a detector defect.
5. Either way, the regression must be explicitly reviewed before approving a
   new baseline. Never auto-refresh baselines in CI.

## Reported observations vs reproduced measurements

Reported false-positive examples from external sources are observations, not
independently reproduced measurements. The evaluator produces reproduced
measurements against the independent corpus. Distinguish the two: a reported
observation may inform a corpus addition, but only a reproduced measurement
counts as evaluation evidence.
